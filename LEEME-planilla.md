# Inscripciones: cómo funciona

- La gente completa todo en la web. Al confirmar, la web manda los datos a un Formulario de Google por atrás
  (nadie ve el formulario). Cada inscripción cae como una fila en la planilla "Oasis Cup - Inscripciones",
  pestaña "Respuestas de formulario 1". No llegan mails.
- Para aprobar un pago, escribí en la columna **Estado** de esa fila: `Seña pagada` o `Pagado`.
  Vacío = pendiente: el color queda reservado 48 horas. `Cancelado` libera el color en el momento.
- La pestaña "Para la web (no tocar)" es lo único publicado: código, categoría, equipo, camiseta y estado.
  La web la lee para saber qué colores están tomados. Puede tardar unos minutos en actualizarse.
- No cambies el nombre ni el orden de las preguntas del formulario: la web las usa por su código.
